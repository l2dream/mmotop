# Правила дизайна MMOTOP

Систематизация внешнего вида сайта. **Читать перед любой работой с видом
сайта.** Если правило меняется — исправить его здесь и записать в раздел
«Изменения» внизу: что, когда и почему. Если просьба противоречит правилу —
напомнить правило и спросить: исключение или меняем правило.

Сейчас правила относятся к **тёмной теме**; светлую систематизируем после.
Форма и радиусы — для обеих тем. Исходник — PDF владельца «MMOTOP — правила
формы и цвета», разобран по пунктам 19–20 ноября 2026.

Стили лежат в конце `app/assets/css/main.css`, блок «Design system, dark
theme».

## 1. Форма

| Форма | Для чего | Элементы |
|---|---|---|
| **Пуговица** (круг) | кнопка внутри другого элемента | фильтр в поиске, номера мест, стрелки и перемешивание в шапке секции, пуговица в табе More, стрелка в «Назад», «−»/«+» в Rates |
| **Скруглённый квадрат** | самостоятельный элемент | логин, язык, поиск, табы, карточки, Apply, Save, Visit website, Голосовать, Add a server, «Назад» |
| **Пилюля** | только переключатели и статусы | тумблер карусели, бейдж статуса (ALREADY STARTED) |

Исключения: «наверх» — круг; луна (тема) — без фона и рамки.

## 2. Рамка — «дуга света»

У кнопок, пуговиц и знаков рамка — дуга с белой искрой сверху слева,
гаснущая к правому нижнему краю (conic-gradient под маской). Каждый элемент в
своём цвете (цвет секции, металл медали, цвет версии, фиолетовый). На
обычных мониторах — 1,5 px и замкнутая, на чётких экранах — 1 px.

## 3. «Приоткрытая дверь»

Кнопка, которая зовёт нажать — главный шаг дальше. **Горит сразу**, в своём
цвете (не обязательно фиолетовом). Двери: Логин, View more (цвет секции),
Add a server, Visit website (ярче всех), Голосовать (на ступень тише).

**Не двери** — всё остальное. Правило для них: своя цветная рамка, внутри
пусто, значок цвета глобуса на кнопке языка (`#e6e8f8`). Горят — тем видом,
что был у них раньше, ничего нового — только когда активны: под указателем
мыши, включены/открыты, и 0,3 с после касания пальцем (`.is-lit`,
`app/plugins/tap-glow.client.ts`).

«Назад» — не дверь: нейтральная, фиолетовая под указателем.

Заливка «горящего» состояния — **полупрозрачный оттенок**, не сплошной цвет.

## 4. Состояния кнопок

| Кнопка | В покое | Горит |
|---|---|---|
| Стрелка, перемешивание в шапке | рамка цвета секции, белый значок | наведение / касание |
| Тумблер карусели | пустое кольцо, белый значок | включён — оттенок секции |
| View more | дверь, всегда в цвете секции | — |
| Фильтр в поиске | фиолетовая рамка, белый значок | панель открыта; применён — плюс цифра |
| Пуговица в табе More | фиолетовая рамка, белая стрелка | наведение, список открыт, выбрана игра |
| Глобус (язык) | белая рамка | панель языков открыта — фиолетовый |
| Apply | фиолетовая рамка, без заливки | в фильтре что-то изменено |
| Reset | текст без рамки, тусклый | что-то выбрано — почти белый |
| «Наверх» | как кнопка языка | наведение — фиолетовый |
| Луна | приглушённо-серая | наведение — белеет; зона нажатия с кнопку |
| «−» / «+» в Rates | фиолетовая рамка, белый знак | наведение / нажатие |
| Крестик шторки выбора | фиолетовая дуга, белый знак | наведение / касание |

Перемешивание: значок делает полный оборот, строки плавно переезжают на
новые места (`ShuffleButton.vue`, FLIP).

## 5. Поверхности

- **Контент** (строки серверов, полоса табов, инфо-плашки на странице
  сервера) — стекло, как есть, не трогать. **Без дуги света**: плашки —
  информация, не кнопки (`.server-facts > div` не входит в списки дуги).
- **Ввод** (поиск, выпадающие списки, поля кабинета, поиск языка,
  Description) — та же дуга с бликом, но **вдвое тише** кнопок. Фокус —
  фиолетовая линия 2 px, без свечения.
- **Выбор из списка** (Game, Version, Server language в фильтре; игра,
  хроника, слово вместо рейта, язык, соцсеть в форме кабинета) — свой
  список, не системный (`PickField.vue`): на телефоне шторка снизу, на
  компьютере панель под полем; сверху строка поиска; выбранный пункт —
  фиолетовая дуга и галочка, как в меню More. Поиск без учёта регистра и
  диакритики, название группы находит всю группу.
  Шторка закрывается смахиванием вниз, кнопкой «Назад» телефона (страница
  остаётся) и крестиком — пуговица, не дверь (см. таблицу состояний).
- **Чипсы рейтов** — это кнопки, не ввод: дуга как у кнопок, выбранный —
  фиолетовый.
- **Знаки** (номера мест, значки версий, эмблемы секций) — цветная рамка без
  серой заливки, без реакции на наведение.

## 6. Радиусы — «матрёшка»

Внутренний = внешний − отступ между ними, но не меньше минимума. Вручную
задаются только внешние слои (переменные в `:root`):

- `--r-outer` 16 px — секции, карточка сервера, панели фильтра и языков;
- `--r-menu` 14 px — меню More;
- `--r-min` 8 px — поля, кнопки, пункты списков внутри;
- `--r-icon` 6 px — значки версий.

Не трогать: кнопки шапки, пилюли, круги, луну, «наверх».

## 7. Цвета

- Фиолетовый — основной цвет и цвет действий/выбранного.
- Красный — только предупреждения и опасные действия, никогда в секциях.
- Номера 1–3 — золото, серебро, бронза; остальные нейтральные.

## Отложено

- **Цвета секций** (по документу: Top Games — `#FFD23F`, Already Started —
  `#A3E635`, New Games — `#D946EF`, Recommended — `#EC4899`; эмблемы в цвет
  секции, кубок золотой). Пока не применены.
- Жёлтая молния на лаймовой Already Started.
- Панель языков: владелец хочет без прокрутки, вариант не выбран.
